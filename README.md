Dashboard de Recursos Humanos & Projetos - Azure CompanyProjeto desenvolvido como desafio prático na plataforma DIO (Digital Innovation One), utilizando o Power BI Desktop para transformar dados relacionais de uma base MySQL (azure_company) num dashboard interativo e dinâmico.
📌 Visão Geral do ProjetoO objetivo principal foi realizar o processo completo de Business Intelligence:Importação e Limpeza de Dados: Extração dos dados relacionais da base azure_company e tratamento de tipos e nomes de colunas no Power Query.Modelagem de Dados: Construção de relacionamentos Muitos-para-Um ($* : 1$) no modelo em estrela/floco de neve entre as tabelas.Construção de Indicadores Visuais: Criação de visuais para acompanhamento de KPIs de Recursos Humanos e alocação de projetos.
🛠️ Estrutura do Modelo de DadosO modelo de dados é composto por 6 tabelas interligadas:department: Informações dos departamentos da empresa.employee: Dados dos colaboradores (salário, género, departamento).dependent: Dependentes associados aos funcionários.dept_locations: Localizações geográficas dos departamentos.project: Projetos desenvolvidos pela organização.works_on: Registo de horas trabalhadas por funcionário em cada projeto.
📈 Indicadores e Visuais do DashboardTotal de Colaboradores (KPI Card): Contagem distinta de funcionários registados.Soma de Salário por Departamento (Gráfico de Colunas): Distribuição do custo salarial total por setor (Research, Administration, Headquarters).Distribuição por Género (Gráfico de Rosca): Proporção entre colaboradores masculinos e femininos.Horas Trabalhadas por Projeto (Gráfico de Barras): Alocação do total de horas investidas em cada projeto da empresa.Filtro Dinâmico (Segmentador de Dados): Permite filtrar todas as métricas do painel por departamento.
